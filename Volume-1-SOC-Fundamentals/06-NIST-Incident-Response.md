# SOC Analyst and NIST Framework

A SOC Analyst contributes throughout the lifecycle:

Preparation:

- Understand tools and procedures

Detection:

- Investigate alerts

Containment:

- Support response actions

Recovery:

- Verify systems are safe

Post-Incident:

- Document findings

---

# Example Scenario

A user account shows suspicious login activity.

Detection:

- SIEM generates an alert.

Analysis:

- Analyst reviews authentication logs.

Containment:

- Account is temporarily disabled.

Eradication:

- Password reset and malicious access removed.

Recovery:

- User access restored.

Post-Incident:

- Detection rules improved.

---

# NIST vs SOC Operations

NIST provides the process.

SOC teams provide the people, tools, and actions needed to execute that process.

Together they create an effective incident response capability.

---

# Key Takeaways

- NIST provides a structured incident response framework.
- Preparation improves response effectiveness.
- Detection and analysis identify threats.
- Containment limits damage.
- Post-incident reviews improve future security.
